1) O que é este app

Aplicação Streamlit para análise quantitativa de ações com dois fluxos principais:

  • Screener Diário: identifica ativos em possível região de compra (IFR2 + tendência + liquidez).
  • O Garimpo (Mining): roda backtest em lote e gera ranking de desempenho vs buy & hold.

Mercados suportados: B3, NYSE/NASDAQ e modo combinado.

2) Aviso importante

Ferramenta de análise. Não executa ordens de compra/venda. Retorno passado não garante retorno futuro.

3) Requisitos

  • Python 3.12+
  • Ambiente virtual (venv) recomendado
  • Dependências instaladas via requirements.txt
  • Internet para downloads via yfinance

4) Instalação e execução

cd /mnt/c/Dev/IFR2
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

./venv/bin/streamlit run ifr2_app.py \
  --server.address 0.0.0.0 \
  --server.port 8501 \
  --server.headless true \
  --browser.gatherUsageStats false \
  --server.fileWatcherType none

Acesse em: http://localhost:8501

6) Regras da estratégia

6.1 Indicadores

  • IFR2 (RSI 2 períodos)
  • SMA200
  • Bullish = Close > SMA200
  • Vol_Fin = Close * Volume
  • Vol_Fin_Medio = média de 21 períodos
  • Max_Prev = máxima anterior (shift)

Obs.: com menos de 200 candles, o cálculo estratégico não é válido.

6.2 Regra do Screener

  • IFR2 < threshold
  • Preço acima da SMA200 (Bullish)
  • Volume financeiro médio acima do mínimo

6.3 Regra do Backtest

Entrada: IFR2 < threshold e Bullish.

Saída: IFR2 > 70 ou Close > Max_Prev.

7) Uso da interface (passo a passo)

7.1 Sidebar

  1. Escolha mercado: B3, NYSE/NASDAQ ou Ambos.
  2. Escolha cesta (snapshot, legado ou customizada).
  3. Refine ativos no multiselect.
  4. Defina threshold IFR2, liquidez e período histórico.

7.2 Aba "Screener Diário"

  1. Clique em Executar Varredura.
  2. Veja barra de progresso de download.
  3. Analise tabela com colunas: Ticker, Preço, Moeda, Mercado, IFR2, Acima SMA200, Vol Fin Médio e Sinal.

7.3 Aba "O Garimpo (Mining)"

  1. Clique em Iniciar Mineração.
  2. O app roda backtest por ativo.
  3. Veja ranking por Alpha e curvas de capital Top 5.

12) Troubleshooting

App não abre

ss -ltnp | grep :8501 || true

Falhas de download

  • Reduza a quantidade de ativos no multiselect.
  • Use período menor (ex.: 1y).
  • Atualize snapshots e tente novamente.

Ativo B3 sem dados

Use ticker com sufixo .SA (ex.: PETR4.SA).

Sem sinais no screener

Pode ser normal dependendo dos filtros (IFR2, tendência e liquidez).

13) Boas práticas

  1. Atualize universos antes de rodar em escala.
  2. Valide em subset pequeno antes de universo completo.
  3. Guarde benchmark e auditoria como evidência.
  4. Rode pytest antes de fechar fase/sprint.
